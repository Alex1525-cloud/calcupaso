Guías de métodos de integración

Cuándo usar cada método, cómo se aplica y un ejemplo que puedes resolver con un clic.

Integrales inmediatas

Cuándo: el integrando ya aparece en la tabla básica, o es una suma de esos casos.

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C   (n ≠ −1)
∫ dx/x = ln|x| + C  ·  ∫ eˣ dx = eˣ + C
∫ sen x dx = −cos x + C  ·  ∫ cos x dx = sen x + C
∫ sec²x dx = tan x + C
  1. Separa la suma en varias integrales (linealidad).
  2. Saca las constantes fuera de la integral.
  3. Aplica la fórmula de la tabla a cada término.

Sustitución (cambio de variable)

Cuándo: dentro de la integral hay una función g(x) y también su derivada g′(x), o algo proporcional a ella.

∫ f(g(x))·g′(x) dx = ∫ f(u) du,   con u = g(x)
  1. Elige u como la expresión "de adentro": el argumento de un seno, el exponente de e o lo que está bajo una raíz.
  2. Deriva: du = g′(x) dx y despeja dx.
  3. Reescribe todo en u. Si queda alguna x, la elección no sirve.
  4. Integra en u y regresa a x.

Por partes

Cuándo: hay un producto de dos funciones de distinto tipo, como x·eˣ, x·sen x o ln x.

∫ u dv = u·v − ∫ v du
"Un Día Vi Una Vaca Vestida De Uniforme"

Qué elegir como u (regla ILATE): Inversa (arctan, arcsen) → Logarítmica (ln) → Algebraica (x, x²) → Trigonométrica (sen, cos) → Exponencial (eˣ). La que aparece primero es u; el resto es dv.

  1. Deriva u para obtener du. Integra dv para obtener v.
  2. Arma u·v − ∫ v du. La nueva integral debe ser más sencilla.
  3. Si vuelve a aparecer la integral original (eˣ·sen x), trátala como incógnita I y despéjala.

Trigonométricas

Cuándo: potencias o productos de senos y cosenos.

sen²θ = (1 − cos 2θ)/2  ·  cos²θ = (1 + cos 2θ)/2
sen²θ + cos²θ = 1  ·  tan²θ = sec²θ − 1
  1. Potencia impar de seno (o de coseno): separa uno y cambia el resto con sen² = 1 − cos². Luego sustituye u = cos x.
  2. Ambas potencias pares: baja el grado con las fórmulas del ángulo doble.
  3. sen A·cos B con ángulos distintos: convierte el producto en suma.

Sustitución trigonométrica

Cuándo: aparece √(a² − x²), √(a² + x²) o √(x² − a²).

√(a² − x²): x = a·sen θ
√(a² + x²): x = a·tan θ
√(x² − a²): x = a·sec θ
  1. Haz el cambio y simplifica la raíz con la identidad pitagórica.
  2. Integra en θ.
  3. Dibuja el triángulo rectángulo para regresar a x.

Fracciones parciales

Cuándo: el integrando es un cociente de polinomios P(x)/Q(x).

(3x + 5)/((x − 1)(x + 2)) = A/(x − 1) + B/(x + 2)
  1. Si grado(P) ≥ grado(Q), divide primero.
  2. Factoriza el denominador.
  3. Factor lineal → A/(x − r). Factor repetido → A/(x − r) + B/(x − r)². Cuadrático sin raíces reales → (Bx + C)/(x² + px + q).
  4. Encuentra las constantes igualando coeficientes y luego integra cada fracción (dan ln y arctan).

a·y″ + b·y′ + c·y = g(x)

Condiciones iniciales (opcional)

Con a = 0 resuelve una ecuación de primer orden b·y′ + c·y = g(x). El lado derecho puede tener polinomios, e^(ax), sen(bx) y cos(bx).

dy/dx = f(x, y)

Detecta el método: variables separables, lineal (factor integrante), homogénea (y = vx) o Bernoulli. Ejemplos: x*y, -2y + x, (x^2+y^2)/(x*y), x*y^2 - y/x.

M(x, y) dx + N(x, y) dy = 0

Si no es exacta, busca un factor integrante que dependa solo de x o solo de y.

a·x²y″ + b·xy′ + c·y = 0

Guía rápida

Lineales de 2.º orden con coeficientes constantes

  1. Resuelve la homogénea con la ecuación característica ar² + br + c = 0.
  2. Según las raíces: distintas → C₁e^(r₁x) + C₂e^(r₂x); doble → (C₁ + C₂x)e^(rx); complejas α ± βi → e^(αx)(C₁cos βx + C₂sen βx).
  3. Propón una solución particular del mismo tipo que g(x) (coeficientes indeterminados). Si choca con la homogénea, multiplica por x.
  4. Suma ambas y, si hay condiciones iniciales, despeja C₁ y C₂.

Lineales de 1.er orden

y′ + P(x)·y = Q(x)  →  μ = e^(∫P dx)
  1. Calcula el factor integrante μ.
  2. Multiplica toda la ecuación: (μ·y)′ = μ·Q.
  3. Integra ambos lados y despeja y.

Variables separables

dy/dx = g(x)·h(y)  →  ∫ dy/h(y) = ∫ g(x) dx
  1. Deja todo lo de y con dy y todo lo de x con dx.
  2. Integra cada lado.
  3. Agrega una sola constante C y, si se puede, despeja y.

Sumas de términos k·tⁿ·e^(at)·sen(bt) o cos(bt).

Cociente de polinomios en s; se separa en fracciones parciales.

a·y″ + b·y′ + c·y = g(t)

Tabla y propiedades

Tabla básica

L{1} = 1/s
L{tⁿ} = n!/sⁿ⁺¹
L{e^(at)} = 1/(s − a)
L{sen bt} = b/(s² + b²)
L{cos bt} = s/(s² + b²)

Propiedades

Linealidad: L{af + bg} = aF + bG
Traslación: L{e^(at)f(t)} = F(s − a)
L{tⁿf(t)} = (−1)ⁿ F⁽ⁿ⁾(s)
L{y′} = sY − y(0)
L{y″} = s²Y − s·y(0) − y′(0)

Resolver una EDO con Laplace

  1. Transforma ambos lados usando L{y′} y L{y″}; las condiciones iniciales entran solas.
  2. Despeja Y(s): queda un cociente de polinomios.
  3. Sepáralo en fracciones parciales.
  4. Aplica la tabla al revés para obtener y(t).

Integrales · Método 2

Sustitución o cambio de variable

La idea

Es la regla de la cadena al revés. Si al derivar f(g(x)) aparece f′(g(x))·g′(x), entonces una integral que tenga "algo de adentro" y "la derivada de ese algo" se simplifica llamando u a lo de adentro.

∫ f(g(x))·g′(x) dx = ∫ f(u) du,   con u = g(x), du = g′(x) dx

Cómo reconocerla

  • Hay una composición: algo dentro de un seno, de una raíz, de una potencia o en el exponente de e.
  • La derivada de lo de adentro aparece multiplicando (aunque sea con otro número delante).
  • Una fracción donde el numerador es (casi) la derivada del denominador: da un logaritmo.

Qué elegir como u

  • El argumento de la función: en cos(x²), u = x².
  • Lo que está bajo la raíz o elevado a una potencia: en (x² + 1)⁵, u = x² + 1.
  • El exponente: en e^(3x²), u = 3x².
  • El denominador: en {{2x|x² + 1}}, u = x² + 1.

Paso a paso

  1. Elige u y calcula du = u′ dx.
  2. Despeja lo que necesites (por ejemplo x dx = {{du|2}}).
  3. Reescribe toda la integral en u. Si queda alguna x, prueba otra u o despeja x en función de u.
  4. Integra en u.
  5. Regresa a x reemplazando u.

Ejemplo resuelto: ∫ x·(x² + 1)⁵ dx

  1. Lo de adentro es x² + 1 y su derivada 2x aparece (falta el 2). Tomamos u = x² + 1.
  2. du = 2x dx → x dx = {{du|2}}.
  3. ∫ u⁵·{{du|2}} = {{1|2}}·{{u⁶|6}} = {{u⁶|12}}.
  4. Regresamos: {{(x² + 1)⁶|12}} + C.

Logaritmo: ∫ {{eˣ|1 + eˣ}} dx

  1. El numerador eˣ es la derivada del denominador. u = 1 + eˣ, du = eˣ dx.
  2. ∫ {{du|u}} = ln|u| → ln(1 + eˣ) + C.

Integral definida: cambia también los límites

∫₀¹ 2x·e^(x²) dx con u = x²: si x = 0 → u = 0; si x = 1 → u = 1. Queda ∫₀¹ eᵘ du = e − 1. No hace falta regresar a x.

Errores comunes

  • Cambiar la función pero no el dx.
  • Dejar mezcladas x y u en la integral.
  • En definidas, usar los límites de x con la función en u.

∫ sen x·cos⁴x dx

∫ {{ln x|x}} dx

Integrales · Método 3

Integración por partes

La idea

Sale de la derivada de un producto. Sirve para integrales de un producto de dos funciones de distinto tipo, donde derivar una la simplifica.

∫ u dv = u·v − ∫ v du
"Un Día Vi Una Vaca Vestida De Uniforme"

Cómo reconocerla

  • x·eˣ, x²·sen x, x·ln x: polinomio por otra función.
  • eˣ·sen x, eˣ·cos x: exponencial por trigonométrica (caso cíclico).
  • Una sola función que no está en la tabla pero cuya derivada sí es fácil: ln x, arctan x, arcsen x (se toma dv = dx).

Qué elegir como u: regla ILATE

Toma como u la función que aparezca primero en esta lista. Lo demás es dv.

Inversas
arctan, arcsenLogarítmicas
ln xAlgebraicas
x, x², √xTrigonométricas
sen, cosExponenciales
eˣ, 2ˣ

Por qué funciona: las de la izquierda se simplifican al derivarlas (ln x → 1/x; x² → 2x → 2) y las de la derecha son fáciles de integrar.

Paso a paso

  1. Elige u con ILATE y el resto es dv (incluido el dx).
  2. Deriva u para obtener du e integra dv para obtener v.
  3. Escribe u·v − ∫ v du.
  4. La nueva integral debe ser más sencilla. Si no lo es, cambia la elección.

Ejemplo resuelto: ∫ x·eˣ dx

  1. x es algebraica (A) y eˣ exponencial (E). A va antes que E: u = x, dv = eˣ dx.
  2. du = dx, v = eˣ.
  3. ∫ x·eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C.

Caso cíclico: ∫ eˣ·sen x dx

  1. Llamamos I a la integral. u = sen x, dv = eˣ dx: I = eˣ sen x − ∫ eˣ cos x dx.
  2. Otra vez por partes con u = cos x: ∫ eˣ cos x dx = eˣ cos x + ∫ eˣ sen x dx = eˣ cos x + I.

Integrales · Método 6

Fracciones parciales

La idea

Una fracción de polinomios difícil se separa en fracciones simples cuyas integrales son logaritmos, potencias o arcotangentes.

Antes de empezar

  • Si el grado del numerador es mayor o igual que el del denominador, primero divide los polinomios.
  • Si el numerador es la derivada del denominador, no hace falta: es una sustitución que da ln.

Paso a paso

  1. Factoriza el denominador.
  2. Escribe la suma de fracciones con constantes desconocidas.
  3. Multiplica todo por el denominador y halla las constantes. Atajo: reemplaza x por cada raíz (método de "tapar"); si faltan constantes, iguala coeficientes.
  4. Integra cada fracción.

Factores lineales distintos: ∫ {{3x + 5|x² + x − 2}} dx

  1. x² + x − 2 = (x − 1)(x + 2), así que {{3x + 5|(x − 1)(x + 2)}} = {{A|x − 1}} + {{B|x + 2}}.
  2. 3x + 5 = A(x + 2) + B(x − 1). Con x = 1: 8 = 3A → A = {{8|3}}. Con x = −2: −1 = −3B → B = {{1|3}}.

EDO de 1.er orden

Variables separables

Cómo reconocerla

El lado derecho se puede escribir como un producto de una función solo de x por una función solo de y: {{dy|dx}} = g(x)·h(y).

Ejemplos: y′ = xy, y′ = {{x²|y}}, y′ = eˣ⁺ʸ = eˣ·eʸ. No es separable: y′ = x + y.

Paso a paso

  1. Pasa todo lo de y con dy a un lado y todo lo de x con dx al otro: {{dy|h(y)}} = g(x) dx.
  2. Integra ambos lados.
  3. Pon una sola constante C.
  4. Despeja y si se puede; si hay condición inicial, halla C.

Ejemplo resuelto: y′ = xy, con y(0) = 2

  1. Separamos: {{dy|y}} = x dx.
  2. Integramos: ln|y| = {{x²|2}} + C.
  3. Despejamos: y = C·e^(x²/2).
  4. y(0) = 2 → C = 2. Resultado: y = 2e^(x²/2).

Cuidado: al dividir entre h(y) puedes perder soluciones donde h(y) = 0. En este ejemplo, y = 0 también es solución (corresponde a C = 0).

Practica

y′ = {{x²|y}}

{{y²|2}} = {{x³|3}} + C

EDO de 1.er orden

Ecuaciones homogéneas

Cómo reconocerla

El lado derecho depende solo del cociente {{y|x}}. Prueba: si cambias x por tx e y por ty, la t se cancela. Pasa cuando todos los términos tienen el mismo grado, como {{x² + y²|xy}}.

Paso a paso

  1. Cambia y = v·x, entonces y′ = v + x·v′.
  2. Sustituye: la ecuación queda separable en v y x.
  3. Resuélvela y regresa con v = {{y|x}}.

Ejemplo: y′ = {{x² + y²|xy}}

  1. Dividimos entre x²: y′ = {{1 + (y/x)²|y/x}} = {{1|v}} + v.
  2. v + x v′ = {{1|v}} + v → x v′ = {{1|v}}.
  3. Separamos: v dv = {{dx|x}} → {{v²|2}} = ln|x| + C.
  4. Regresamos: y² = 2x²(ln|x| + C).

EDO de 1.er orden

Ecuaciones exactas

Cómo reconocerla

Escríbela como M(x, y) dx + N(x, y) dy = 0 y compara derivadas cruzadas: si {{∂M|∂y}} = {{∂N|∂x}}, es exacta. Significa que existe una función F(x, y) con Fx = M y Fy = N, y la solución es F = C.

Paso a paso

  1. Verifica My = Nx.
  2. Integra M respecto de x: F = ∫ M dx + g(y).
  3. Deriva F respecto de y e iguala a N para hallar g′(y).
  4. Integra g′ y escribe F(x, y) = C.

Ejemplo: (2xy + 3) dx + (x² + 4y) dy = 0

  1. My = 2x, Nx = 2x. Es exacta.
  2. F = ∫ (2xy + 3) dx = x²y + 3x + g(y).
  3. Fy = x² + g′(y) = x² + 4y → g′ = 4y → g = 2y².
  4. Resultado: x²y + 3x + 2y² = C.

Si no es exacta: factor integrante

  • Si {{My − Nx|N}} depende solo de x, usa μ(x) = e^(∫ de eso dx).
  • Si {{Nx − My|M}} depende solo de y, usa μ(y) = e^(∫ de eso dy).

(3xy + y²) dx + (x² + xy) dy = 0

My − Nx = (3x + 2y) − (2x + y) = x + y, y dividido entre N = x(x + y) da {{1|x}}. Entonces μ = x. Multiplicando, la ecuación queda exacta y su solución es x³y + {{x²y²|2}} = C.

EDO de 1.er orden

Lineales de primer orden

Cómo reconocerla

Se puede escribir como y′ + P(x)·y = Q(x): y e y′ a la primera potencia, sin productos entre ellas. Si y′ tiene un coeficiente, divide toda la ecuación entre él.

Paso a paso

  1. Lleva la ecuación a la forma y′ + P(x)y = Q(x).
  2. Calcula el factor integrante μ = e^(∫P dx). No pongas constante aquí.
  3. Multiplica toda la ecuación por μ: el lado izquierdo se convierte en (μ·y)′.
  4. Integra: μ·y = ∫ μ·Q dx + C.
  5. Despeja y.

Ejemplo: y′ + 2y = x

  1. P = 2, Q = x. μ = e^(2x).
  2. (e^(2x)y)′ = x·e^(2x).
  3. Por partes: ∫ x e^(2x) dx = {{x e^(2x)|2}} − {{e^(2x)|4}}.
  4. Resultado: y = {{x|2}} − {{1|4}} + C e^(−2x).

Coeficientes variables: x y′ + y = x²

Dividimos entre x: y′ + {{y|x}} = x. μ = e^(ln x) = x. (x y)′ = x² → x y = {{x³|3}} + C → y = {{x²|3}} + {{C|x}}.

EDO de 1.er orden

Ecuación de Bernoulli

Cómo reconocerla

Es "casi lineal" pero el lado derecho tiene una potencia de y: y′ + P(x)y = Q(x)·yⁿ, con n ≠ 0, 1.

Paso a paso

  1. Cambia v = y¹⁻ⁿ.
  2. La ecuación se vuelve lineal en v: v′ + (1 − n)P·v = (1 − n)Q.
  3. Resuélvela con factor integrante y regresa a y.

Ejemplo: y′ + {{y|x}} = x y²

  1. n = 2 → v = y⁻¹, y la ecuación queda v′ − {{v|x}} = −x.
  2. μ = e^(−ln x) = {{1|x}}: ({{v|x}})′ = −1 → {{v|x}} = −x + C → v = Cx − x².
  3. Resultado: y = {{1|Cx − x²}}.

Riccati (mención)

y′ = P(x) + Q(x)y + R(x)y². Si conoces una solución y₁, el cambio y = y₁ + {{1|v}} la vuelve lineal.

EDO de 2.º orden

Cuándo usarla

  • Falta y: la ecuación tiene x, y′, y″ pero no y. Cambia p = y′, y″ = p′.
  • Falta x: tiene y, y′, y″ pero no x. Cambia p = y′, y″ = p·{{dp|dy}}.

En ambos casos queda una EDO de primer orden en p.

Falta y: x y″ + y′ = 0

p = y′: x p′ + p = 0 → (x p)′ = 0 → p = {{C₁|x}} → y = C₁ ln|x| + C₂.

Falta x: y y″ = (y′)²

y·p{{dp|dy}} = p² → {{dp|p}} = {{dy|y}} → p = C₁y → y′ = C₁y → y = C₂e^(C₁x).

Cómo reconocerla

La potencia de x coincide con el orden de la derivada: ax²y″ + bxy′ + cy = 0. Aparece en problemas con simetría radial, como placas y cilindros.

Paso a paso

  1. Prueba y = xʳ: y′ = r xʳ⁻¹, y″ = r(r − 1)xʳ⁻².

r(r − 1) − 2r + 2 = r² − 3r + 2 = 0 → r = 1, 2 → y = C₁x + C₂x².

La idea

Pasos para analizar una función

  1. Calcula f′(x) y resuelve f′(x) = 0 (puntos críticos).
  2. Haz una tabla de signos de f′ entre los críticos: así sabes dónde crece y decrece.
  3. Clasifica cada crítico con f″ (o con el cambio de signo de f′).
  4. Resuelve f″ = 0 para los posibles puntos de inflexión.

Problemas de optimización (paso a paso)

  1. Dibuja y nombra las variables.
  2. Escribe la función objetivo (lo que se maximiza o minimiza: área, costo, volumen).
  3. Usa la restricción (el dato fijo) para dejarla en una sola variable.
  4. Define el intervalo válido (longitudes positivas, etc.).
  5. Deriva, iguala a 0 y compara con los extremos del intervalo.

Se cortan cuadrados de lado x en las esquinas. Volumen V(x) = x(20 − 2x)², con 0 ≤ x ≤ 10.

Si dos cantidades dependen del tiempo, deriva la relación entre ellas respecto a t (regla de la cadena). Ejemplo: en un cono que se llena de agua, V = πr²h/3; derivando respecto a t relacionas dV/dt con dh/dt.

Métodos numéricos

Interpolación de Lagrange y de Newton

Con n + 1 puntos hay un único polinomio de grado ≤ n que pasa por todos. Lagrange y Newton dan el mismo polinomio, escrito distinto.

  • Lagrange: P(x) = Σ yᵢ·Lᵢ(x), con Lᵢ(x) = Π (x − xⱼ)/(xᵢ − xⱼ). Directo para pocos puntos.
  • Newton (diferencias divididas): P(x) = f[x₀] + f[x₀, x₁](x − x₀) + f[x₀, x₁, x₂](x − x₀)(x − x₁) + … Si agregas un punto, solo sumas un término.

Con muchos puntos equiespaciados el polinomio oscila en los bordes (fenómeno de Runge). Es mejor usar trazadores (splines) o pocos puntos cercanos.

En ingeniería se usa para leer tablas: por ejemplo, interpolar un coeficiente de una tabla de la norma entre dos valores.

Sistemas lineales: LU, Jacobi y Gauss-Seidel

LU: A = L·U. Luego L·y = b (hacia adelante) y U·x = y (hacia atrás). Conviene si resuelves muchos sistemas con la misma A, como en el método de rigidez con varios estados de carga.

Jacobi: despeja cada incógnita de su ecuación y usa los valores de la iteración anterior. Gauss-Seidel: igual, pero usa cada valor nuevo apenas lo calcula; suele converger el doble de rápido.

Convergencia garantizada si la matriz es diagonalmente dominante: |aᵢᵢ| > Σ |aᵢⱼ| (j ≠ i) en cada fila. Si no lo es, intenta reordenar las ecuaciones.

Ecuaciones: lineales, cuadráticas y de grado mayor

  • Lineal (ax + b = 0): x = −b/a.
  • Cuadrática: factoriza si se puede; si no, x = (−b ± √(b² − 4ac))/2a.
  • Grado 3 o más: busca raíces racionales con Ruffini y baja el grado hasta llegar a una cuadrática.
  • Con fracciones: multiplica por el MCM de los denominadores y descarta las soluciones que los anulan.
  • Bicuadrada (ax⁴ + bx² + c = 0): cambia u = x².

Ruffini paso a paso

  1. Candidatos a raíz: ± divisores del término independiente / divisores del coeficiente principal.
  2. Prueba un candidato con la tabla: baja el primer coeficiente, multiplica por la raíz, suma con el siguiente y repite.
  3. Si el último número (residuo) es 0, encontraste una raíz y la fila de abajo es el cociente.

Candidatos: ±1, ±2, ±3, ±6. Con x = 1: 1 | −5 | 6 | 0 → queda x² − 5x + 6 = (x − 2)(x − 3). Soluciones: 1, 2, 3.

Matemática básica

Inecuaciones: método de los puntos críticos

  1. Pasa todo a un lado: P(x)/Q(x) ≷ 0. Nunca multipliques por algo con x, porque su signo puede cambiar.
  2. Halla los puntos críticos: ceros del numerador y del denominador.
  3. Ubícalos en la recta y prueba un valor en cada tramo para saber el signo.
  4. Elige los tramos con el signo pedido. Con ≤ o ≥ incluye los ceros del numerador; los del denominador nunca.

(x − 1)/(x + 2) ≥ 0

Críticos: 1 (numerador) y −2 (denominador). Signos: + en (−∞, −2), − en (−2, 1), + en (1, ∞). Solución: ⟨−∞, −2⟩ ∪ [1, +∞⟩.

MCD, MCM, fracciones y porcentajes

  • MCD: factores primos comunes con el menor exponente. Sirve para simplificar fracciones y repartir en partes iguales.
  • MCM: todos los factores con el mayor exponente. Sirve para sumar fracciones y para saber cuándo coinciden eventos periódicos.
  • a % de b = a·b/100. Variación % = (final − inicial)/inicial·100.
  • Porcentajes sucesivos se multiplican: dos descuentos del 10 % equivalen a 0.9·0.9 = 0.81, es decir, 19 %.
  • Regla de tres directa: si una aumenta, la otra también (multiplicas en cruz). Inversa: si una aumenta, la otra disminuye (multiplicas en línea).
